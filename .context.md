# Context Helper

> Quick reference for AI agents to understand the AgenticAI .NET 10 template project structure.

## Quick Navigation

### Core Directories
| Directory | Purpose | Key Files |
|-----------|---------|-----------|
| `src/` | C# source code organized by domain | Feature folders with Services, Handlers, Entities |
| `tests/` | xUnit test project | Unit, Integration test folders |
| `docs/` | Project documentation | `architecture.md`, `conventions.md`, `specs/` |
| `.github/` | GitHub & Copilot config | `copilot-instructions.md`, instructions/, prompts/, chatmodes/ |

### Configuration Files
| File | Purpose |
|------|---------|
| `.csproj` | C# project file with NuGet dependencies |
| `.github/copilot-instructions.md` | GitHub Copilot guidelines for C#/.NET |
| `.github/apm.yml` | Project metadata & build scripts |

## Common Tasks

### Setting Up a New Domain/Feature
1. Create specification: `docs/specs/[feature].spec.md`
2. Read: `.github/instructions/backend.instructions.md` (Railway-Oriented Programming patterns)
3. Use prompt: `.github/prompts/feature-implementation.prompt.md`
4. Structure: `src/[DomainName]/` with Entities/, Services/, Handlers/, Repositories/, DTOs/
5. Add tests: `tests/[DomainName].Tests/` with Unit/ and Integration/ folders

### Fixing a Bug in C#/.NET
1. Review: `.github/instructions/backend.instructions.md`
2. Use prompt: `.github/prompts/bug-fix.prompt.md`
3. Add regression test to `tests/`
4. Run: `dotnet test` to verify fix
5. Update `.memory.md` if it's a pattern or gotcha

### Code Review
1. Use chat mode: `.github/chatmodes/reviewer.chatmode.md`
2. Check: Railway-Oriented Programming patterns, Result<T> usage, async/await compliance
3. Verify: Tests pass (`dotnet test`), code builds (`dotnet build`), no warnings

## Tech Stack Quick Reference

### Core Runtime
- **Language**: C# 13.0
- **Runtime**: .NET 10
- **Pattern Library**: CSharpFunctionalExtensions (Railway-Oriented Programming)

### Backend Framework
- **Web Framework**: ASP.NET Core
- **ORM**: Entity Framework Core
- **Validation**: FluentValidation (recommended)

### Testing & Quality
- **Testing**: xUnit with Moq
- **Code Analysis**: SonarAnalyzer.CSharp, Microsoft.CodeAnalysis.NetAnalyzers, Meziantou.Analyzer
- **Build Quality**: TreatWarningsAsErrors enabled
- **Documentation**: XML doc comments required
- **Nullable Reference Types**: Enabled (`#nullable enable`)
- **Target Coverage**: Minimum 80% (see `.memory.md` for detailed breakdown)

### Database
- **Default**: SQL Server (via EF Core)
- **Alternative**: PostgreSQL (with EF Core provider)

## Key Concepts

### Domain Terms
| Term | Definition |
|------|------------|
| **Railway-Oriented Programming (ROP)** | Using Result<T> to chain operations; success path and failure path branch like train tracks |
| **Result<T> Pattern** | Type-safe error handling: `Result<T>` contains either Success(value) or Failure(error) |
| **Agentic Primitives** | Reusable AI guidance patterns: instructions, prompts, chatmodes, specs, memory |
| **Clean Architecture** | 4-layer separation: Presentation → Application → Business Logic → Data Access |

### Core Patterns
| Pattern | File Location |
|---------|---------------|
| Command Handler | `src/[Domain]/Handlers/[Feature]Handler.cs` |
| Repository Interface | `src/[Domain]/Repositories/I[Entity]Repository.cs` |
| Domain Entity | `src/[Domain]/Entities/[Entity].cs` |
| Value Object | `src/[Domain]/ValueObjects/[ValueObject].cs` |
| DTO (Record) | `src/[Domain]/DTOs/[Entity]Dto.cs` |

## Frequently Needed

### Environment Variables
```bash
ConnectionStrings__DefaultConnection=    # Database connection (SQL Server or PostgreSQL)
Logging__LogLevel__Default=Information    # Logging level
# See appsettings.json for template
```

### Common .NET CLI Commands
```bash
dotnet build            # Build solution
dotnet test             # Run all tests
dotnet test --verbosity:detailed    # Detailed test output
dotnet format           # Format code
dotnet format --verify-no-changes   # Check formatting without applying
dotnet clean            # Clean build artifacts
dotnet run              # Run application
```

## Where to Find Things

- **API Controllers**: `src/[Domain]/Controllers/` or features with endpoints
- **Command Handlers**: `src/[Domain]/Handlers/[Feature]Handler.cs` or `[Feature]CommandHandler.cs`
- **Query Handlers**: `src/[Domain]/Handlers/[Feature]QueryHandler.cs` or `Query[Feature]Handler.cs`
- **Entities & Business Logic**: `src/[Domain]/Entities/`
- **Repositories**: `src/[Domain]/Repositories/` (interfaces) + Infrastructure implementation
- **DTOs**: `src/[Domain]/DTOs/`
- **Value Objects**: `src/[Domain]/ValueObjects/`
- **Tests**: `tests/[Domain].Tests/Unit/` and `tests/[Domain].Tests/Integration/`
